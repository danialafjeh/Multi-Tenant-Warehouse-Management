Learn more :
* Each API key identifies your organization and allows authorized external systems to retrieve product inventory information without requiring a user account.
* You can create multiple keys for different integrations and revoke them whenever necessary.
* API Endpoint : GET /api/v1/products/sku/inventory/
* How to use :
Send a GET request to the endpoint with the product SKU and include your API key in the HTTP Authorization header :
Authorization: Api-Key YOUR_API_KEY
The API returns the product name, SKU, total available quantity across active warehouses, and stock availability status.
* Important: Keep your API keys secret! They provide access to your organization's inventory data.
